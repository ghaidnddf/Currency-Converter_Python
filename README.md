# Currency Converter (EUR Basis) 💶💱

A robust Python command-line tool that fetches real-time currency exchange rates from an API and converts amounts from EUR to various global currencies.

## Features 🚀
- **Real-time Data:** Integration with ExchangeRate-API for up-to-date rates.
- **Input Validation:** Handles invalid currency codes and non-numeric inputs gracefully.
- **Transaction Logging:** Every conversion is automatically saved with a timestamp in `history.txt`.
- **User-Friendly Loops:** Continuous prompts until valid data is provided.
